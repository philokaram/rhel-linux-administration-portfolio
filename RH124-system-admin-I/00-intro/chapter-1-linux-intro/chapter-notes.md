# Chapter 1 - Introduction to Linux

## What is Linux?
Linux is an open source system kernel that manages a computer's hardware and resources.
when combined with other software, it becomes a complete operating system used to run servers, applications, and many devices. 

## What is Open Source?
Open source means software whose source code is available for anyone to view, use, modify, and share.

## Key concepts
- Kernel
- Distribution
- CLI(Command Line Interface)
- Open source license types(Copyleft, Premissive)
